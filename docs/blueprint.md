# **App Name**: LitArticle Scoop

## Core Features:

- DOI Input Area: A text area where users can paste DOIs, separated by commas, semicolons, or new lines. Prefixes like 'https://doi.org/' will be automatically removed.
- DOI Processing & Link Generation: Processes the list of DOIs, generates direct download links based on the provided URL patterns (Wiley, Springer, Emerald, Taylor & Francis, SAGE), and allows users to download the PDFs directly. A maximum of 10 unique DOIs can be processed in the trial version.
- AI-Powered Link Discovery: If direct links aren't found, use a tool that leverages a search engine to search for the DOI. Scrape and extract the PDF link from ResearchGate if available. If not, search and extract from arXiv, if available.

## Style Guidelines:

- Primary color: Light grey or white for clean and professional look.
- Secondary color: Dark grey for text and important elements.
- Accent: Teal (#008080) for buttons and highlights.
- Responsive layout that adapts to different screen sizes (desktop, tablet, mobile).
- Simple and clear icons for download links and status indicators.
